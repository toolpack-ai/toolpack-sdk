# @toolpack-sdk/agents v3.0.0

Date: 2026-08-02

## Highlights

- **`AgentInput.signal` and `AgentRunOptions.signal`** — agents now accept `signal?: AbortSignal`, letting callers cancel an in-flight run from outside (stop button, timeout, HTTP endpoint)
- **Abort propagation through delegation** — `delegate_to_agent` and `delegate_and_forget` forward the parent agent's abort signal into every sub-agent invocation; aborting the root agent stops the entire delegation chain

---

## Breaking changes

None within the agents package. Note that `toolpack-sdk` peer dependency is now `^3.0.0`, which contains breaking changes — see the [toolpack-sdk v3.0.0 release notes](./toolpack-sdk/v3.0.0.md).

---

## New features

### `AgentInput.signal` and `AgentRunOptions.signal`

Both types now accept an optional `signal?: AbortSignal`. Pass an `AbortController`'s signal when invoking an agent to support cancellation.

```typescript
const controller = new AbortController();

const result = await agent.invokeAgent({
  message: 'Do something long-running',
  signal: controller.signal,
});

// Cancel at any time — from a stop endpoint, UI button, or timeout:
controller.abort();
```

**Typical web server pattern:**

```typescript
const activeRuns = new Map<string, AbortController>();

app.post('/api/chat', async (req, res) => {
  const { sessionId, message } = req.body;
  const controller = new AbortController();
  activeRuns.set(sessionId, controller);

  const result = await agent.invokeAgent({ message, signal: controller.signal });
  activeRuns.delete(sessionId);
  res.json(result);
});

app.post('/api/chat/stop', (req, res) => {
  const controller = activeRuns.get(req.body.sessionId);
  if (controller) {
    controller.abort();
    activeRuns.delete(req.body.sessionId);
  }
  res.json({ ok: true });
});
```

---

### Abort propagation through delegation

`delegate_to_agent` and `delegate_and_forget` now pass `signal` from the parent agent's run options into `registry.invoke()`. This means aborting the root agent automatically cancels all sub-agents it has delegated to — no manual wiring needed.

```typescript
// Aborting executiveAgent also stops every agent it delegates to
const controller = new AbortController();
await executiveAgent.invokeAgent({ message: '...', signal: controller.signal });
controller.abort();
```

**Limitation:** The signal fires at tool-round boundaries, not mid-execution. A tool call that has already started finishes its current step before the abort is observed. This is the standard behavior for cooperative cancellation with `AbortSignal`.
