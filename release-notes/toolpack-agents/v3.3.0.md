# @toolpack-sdk/agents v3.3.0

Date: 2026-09-13

## Highlights

- **`maxTokens` run option** — callers can now cap output tokens on a per-run basis via `AgentRunOptions.maxTokens`, mapped directly to `max_tokens` on the provider request

---

## New features

### `AgentRunOptions.maxTokens`

Hard cap on output tokens for a single agent run. When set, it is passed as `max_tokens` to the underlying provider request, overriding any model default. Useful for platforms that need to throttle output size (for example, when an org's credit balance is low).

```typescript
const result = await agent.run('Summarise this document', undefined, {
  maxTokens: 512,
});
```

The field is optional and has no effect when omitted. It is independent of `maxToolRounds` — both can be set together.

| Field | Type | Default |
|---|---|---|
| `maxTokens` | `number` (optional) | Provider default |
