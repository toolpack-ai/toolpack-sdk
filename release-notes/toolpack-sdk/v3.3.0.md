# Toolpack SDK v3.3.0

Date: 2026-09-13

## Highlights

- **`maxTokens` per-run option in agents** — `AgentRunOptions.maxTokens` lets the caller cap output tokens for a single run, passed directly to the provider as `max_tokens`

---

## New features

### `AgentRunOptions.maxTokens` (in `@toolpack-sdk/agents`)

A new optional field on `AgentRunOptions` that hard-caps output tokens for one agent run. Platforms can use this to control output size when credit balances are constrained, without changing model configuration globally.

```typescript
const result = await agent.run('Explain this codebase', undefined, {
  maxTokens: 1024,
  maxToolRounds: 5,
});
```
