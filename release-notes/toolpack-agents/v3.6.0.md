# @toolpack-sdk/agents v3.6.0

Date: 2026-11-15

## Highlights

- **`interceptTool` per run**: stop or change any tool call of one agent run
- **`conversationSearch` option**: leave out the built-in `conversation_search` tool, for example to give the agent your own
- **Agent Mind `kinds`**: choose which kinds of entry an agent remembers (beliefs, reflections, goals)

---

## New features

### `interceptTool` on a run

`AgentRunOptions` accepts `interceptTool`. It is passed to the run's request, so it wraps every tool call the agent makes in that run. It works the same way as in `toolpack-sdk` (see the `toolpack-sdk` v3.6.0 notes): call `run()` to run the tool, or return text without calling it to stop the call.

```typescript
const result = await agent.run('Clean up the reports folder', undefined, {
  interceptTool: async (call, run) => {
    if (call.toolName.startsWith('fs.delete')) return 'Ask the user before deleting anything.';
    return run();
  },
});
```

Runs without `interceptTool` behave as before.

### `conversationSearch` option on `BaseAgent`

Every run that has a conversation gets the built-in `conversation_search` tool, so the model can look up older turns. Set `conversationSearch` to `false` to leave it out. This lets an app give the agent its own search tool under the same name.

```typescript
class SupportAgent extends BaseAgent {
  conversationSearch = false; // the app adds its own conversation_search tool
}
```

The conversation history still loads as before. Only the tool is left out. The default is `true`, so existing agents do not change.

### Agent Mind: choose which kinds an agent remembers

`AgentMindConfig` accepts `kinds`, a list of `'belief'`, `'reflection'` and `'goal'`. The default is all three, as before.

```typescript
class FactsAgent extends BaseAgent {
  mind = {
    embedder: new OllamaEmbedder({ model: 'nomic-embed-text' }),
    kinds: ['belief'], // remembers facts only
  };
}
```

With a shorter list, the kinds that are left out are switched off completely:

| Part of the mind | What changes |
|---|---|
| Mind header | Only holds the chosen kinds. With `['belief']` it has no goals and no reflections |
| Tools | Only the chosen kinds' tools are given to the agent. With `['belief']` there are no goal or reflection tools |
| `mind_recall` | Only searches the chosen kinds, whatever `type` the model asks for. Its `type` option only lists those kinds |
| Store reads | A kind that is left out is not read at all |

Which tools come with each kind:

| Kind | Tools |
|---|---|
| (always) | `mind_recall` |
| `belief` | `mind_believe` |
| `reflection` | `mind_reflect`, `mind_unpin_reflection` |
| `goal` | `mind_set_goal`, `mind_update_goal`, `mind_complete_goal` |

The list must name at least one kind. An empty list (or one with no valid kind) throws when the mind is set up. A kind named twice counts once.

## Compatibility

- Node.js >= 20
- Peer dependency `toolpack-sdk` `^3.6.0` (`AgentRunOptions.interceptTool` uses its `ToolInterceptor` type)
- Peer dependency `@toolpack-sdk/knowledge` `^3.6.0` (optional)
- No breaking changes

## Install

```bash
npm install @toolpack-sdk/agents@3.6.0
```
