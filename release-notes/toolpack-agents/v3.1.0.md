# @toolpack-sdk/agents v3.1.0

Date: 2026-08-10

## Highlights

- **Peer dependency bump** — requires `toolpack-sdk@^3.1.0` and `@toolpack-sdk/knowledge@^3.1.0` (optional) to stay aligned with the multi-tenancy tool and knowledge APIs
- No agent-runtime API changes in this package

---

## Breaking changes

None within the agents package. Peer ranges now require `^3.1.0` for `toolpack-sdk` and `@toolpack-sdk/knowledge`.

If you pin exact `3.0.0` peers, upgrade:

```bash
npm install toolpack-sdk@3.1.0 @toolpack-sdk/knowledge@3.1.0 @toolpack-sdk/agents@3.1.0
```

See the [toolpack-sdk v3.1.0 release notes](../toolpack-sdk/v3.1.0.md) for tool category and override changes, and [knowledge v3.1.0](../toolpack-knowledge/v3.1.0.md) for incremental ingest/delete APIs.

---

## Compatibility

- Node.js >= 20
- Peer dependency `toolpack-sdk` `^3.1.0`
- Peer dependency `@toolpack-sdk/knowledge` `^3.1.0` (optional)

## Install

```bash
npm install @toolpack-sdk/agents@3.1.0
```
