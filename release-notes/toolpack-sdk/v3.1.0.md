# Toolpack SDK v3.1.0

Date: 2026-08-10

## Highlights

- **Tool overrides at init** — `toolOverrides` lets enterprise or host packages replace built-in tools by name after built-ins load
- **Runtime multi-project loading** — `loadToolProjects()` registers several tool projects and rebuilds the BM25 index once; `searchTools()` / `getRegisteredToolNames()` expose registration for tests and inspection
- **Finer tool categories** — the old `network` category is split into `http`, `web`, `github`, and `slack` so modes and `tool.search` can filter more precisely
- **Dynamic `tool.search` categories** — the category enum is built from currently registered tools (excluding `meta`)
- **Skills exports** — `BM25Engine`, `BM25SearchResult`, and `parseSkillFile` are now public exports

---

## Breaking changes

| Change | Migration |
|---|---|
| Tool / project category `network` removed | Use `http`, `web`, `github`, or `slack` as appropriate |
| `CHAT_MODE.allowedToolCategories` | Was `['network']`; now `['http', 'web']` |
| `tool.search` category enum | Was `filesystem`, `network`, `execution`, `system`, `meta`; now includes `http`, `web`, `github`, `slack` instead of `network` (and may be overridden dynamically from registered tools) |

If you filter modes or configs with `category: 'network'`, update those allow/block lists to the new categories.

---

## New features

### `toolOverrides` on `Toolpack.init()`

Pass tool projects that should win over same-named built-ins. They load after built-ins and also feed the dynamic `tool.search` category enum.

```typescript
const sdk = await Toolpack.init({
  provider: 'anthropic',
  tools: true,
  toolOverrides: [enterpriseToolsProject],
});
```

| Field | Type | Default | Description |
|---|---|---|---|
| `toolOverrides` | `ToolProject[]` | `undefined` | Projects loaded after built-ins; same tool name replaces the built-in |

---

### `loadToolProjects()`, `searchTools()`, `getRegisteredToolNames()`

```typescript
await sdk.loadToolProjects([projectA, projectB]); // single BM25 reindex at the end

const { found, tools } = sdk.searchTools('http get', 'http');
const names = sdk.getRegisteredToolNames();
```

`loadToolProject()` still exists and now delegates to `loadToolProjects([project])`.

---

### Category split: `http` / `web` / `github` / `slack`

Built-in HTTP, web scraping/search, GitHub, and Slack tools no longer share `network`. Chat mode allows only `http` and `web` by default.

---

### Dynamic `tool.search` categories

`ToolRouter` builds the `tool.search` schema with categories from `registry.getCategories()` (excluding `meta`). If no categories are registered yet, the static default enum is used.

---

### Public skills exports

```typescript
import { BM25Engine, parseSkillFile } from 'toolpack-sdk';
import type { BM25SearchResult } from 'toolpack-sdk';
```
