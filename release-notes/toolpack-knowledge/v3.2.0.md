# @toolpack-sdk/knowledge v3.2.0

Date: 2026-09-06

## Highlights

- **`VertexAIEmbedder` inline credentials** — pass a parsed service account JSON object via `credentials` instead of relying solely on Application Default Credentials

---

## Breaking changes

None. All changes are additive.

---

## New features

### `VertexAIEmbedder` inline credentials

```typescript
import { VertexAIEmbedder } from '@toolpack-sdk/knowledge';
import serviceAccount from './service-account.json';

const embedder = new VertexAIEmbedder({
  project: 'my-gcp-project',
  location: 'us-central1',
  credentials: serviceAccount,
});
```

| Option | Type | Description |
|---|---|---|
| `credentials` | `Record<string, unknown>` | Parsed service account JSON key. When provided, used instead of Application Default Credentials |

Mirrors the `googleAuthOptions.credentials` pattern already present in `VertexAIAdapter`.
