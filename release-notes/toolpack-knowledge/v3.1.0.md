# @toolpack-sdk/knowledge v3.1.0

Date: 2026-08-10

## Highlights

- **`TextSource`** — ingest plain text with chunking, namespace, and custom metadata (suited to platform / tenant knowledge items)
- **Incremental `ingest()`** — embed and store chunks from a source without clearing existing data
- **`delete()` / `deleteWhere()`** — remove by IDs or by metadata filter (e.g. cascade delete by `knowledge_item_id`)
- **`onAdd` / `onDelete` hooks** — notify an outer sync layer when chunks are added or removed
- **`matchesFilter` export** — reuse metadata filter matching outside `Knowledge`

---

## Breaking changes

None. All APIs in this release are additive.

## New features

### `TextSource`

```typescript
import { TextSource, Knowledge } from '@toolpack-sdk/knowledge';

const source = new TextSource('item-abc', documentBody, {
  namespace: 'tenant-knowledge',
  metadata: { knowledge_item_id: 'abc', tenant_id: 't1' },
  maxChunkSize: 2000,
  chunkOverlap: 200,
});

await knowledge.ingest(source);
```

| Option | Type | Default | Description |
|---|---|---|---|
| `maxChunkSize` | number | `2000` | Max estimated tokens per chunk |
| `chunkOverlap` | number | `200` | Overlap between split parts |
| `namespace` | string | `'text'` | Prefix for deterministic chunk IDs |
| `metadata` | `Record<string, unknown>` | `{}` | Merged into every chunk’s metadata |

---

### `Knowledge.ingest(source)`

Embeds and stores all chunks from a `KnowledgeSource` without clearing the provider. Returns the number of chunks ingested. Use for add/update flows against a persistent store.

---

### `Knowledge.delete(ids)` and `Knowledge.deleteWhere(filter)`

```typescript
await knowledge.delete([chunkId]);

// Cascade-delete all chunks for a platform item
const removed = await knowledge.deleteWhere({ knowledge_item_id: 'abc' });
```

`deleteWhere` loads all chunks, keeps those whose metadata matches every key-value pair in the filter, deletes them, and returns the deleted IDs.

---

### `onAdd` / `onDelete` handlers

```typescript
const knowledge = await Knowledge.create({
  // ...provider, embedder, sources...
  onAdd: ({ id, content, metadata }) => {
    // mirror to platform store
  },
  onDelete: ({ ids, filter }) => {
    // sync deletions
  },
});
```

`add()` fires `onAdd` after a successful provider write. `delete` / `deleteWhere` fire `onDelete`.

---

### Exported `matchesFilter`

```typescript
import { matchesFilter } from '@toolpack-sdk/knowledge';

matchesFilter(chunk.metadata, { tenant_id: 't1' });
```
