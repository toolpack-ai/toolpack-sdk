# Toolpack SDK v2.7.0

Date: 2026-07-27

## Highlights

- **Rules system** — inject always-on behavioral constraints from Markdown files into the system prompt, scoped per mode with an optional `__global__/` folder that applies across all modes sharing the same rules directory
- **Anthropic on Vertex AI provider** — run Claude models through Google Cloud Vertex AI using Application Default Credentials, no Anthropic API key required
- **VertexAI: new models and thinking budget** — `gemini-3.5-flash` and `gemini-3.1-pro-preview` added; configurable thinking token budget for Gemini 2.5+ models
- **Skills: mode-gated auto-injection** — skill auto-injection is now opt-in per mode via `skillInterceptor: true`, eliminating BM25 overhead on modes that don't need it

None.

## New features

### Rules system

Rules are always-on behavioral constraints loaded from Markdown files and appended to the system prompt on every request. Unlike Skills (which are BM25-matched and conditionally injected), Rules fire unconditionally.

Set `rulesDir` on any mode:

```typescript
import { createMode } from 'toolpack-sdk';

const analystMode = createMode({
  name: 'equity-analyst',
  systemPrompt: 'You are an Indian equity market analyst.',
  rulesDir: '.warren/rules',
});
```

**Directory convention:**

```
.warren/rules/
  __global__/
    compliance.md       ← injected for every mode pointing to this directory
  equity-analyst/
    india-only.md       ← injected for this mode only
```

- `__global__/` applies to all modes that share the same `rulesDir` value
- Files are scanned recursively; only `.md` files are loaded
- Files are deduplicated by resolved absolute path — first-seen wins (global before mode-specific)
- Two-level cache: raw file content cached per path, assembled `<rules>` block cached per `modeName:dir`
- Injected last in the system prompt chain (`base → override → mode → rules`), placing them closest to the conversation
- Default path when `rulesDir` is not set: `.toolpack/rules`

**`ModeConfig` change:**

```typescript
interface ModeConfig {
  // ... existing fields ...
  rulesDir?: string;  // new
}
```

**`RuleLoader` is exported** for custom use cases:

```typescript
import { RuleLoader } from 'toolpack-sdk';

const loader = new RuleLoader();
const rules = await loader.loadForMode('equity-analyst', '.warren/rules');
```

### Anthropic on Vertex AI provider (`AnthropicVertexAdapter`)

Run Claude Sonnet 4.5 and Haiku 4.5 on Google Cloud without an Anthropic API key. Authentication is handled by Application Default Credentials (`gcloud auth application-default login`).

```typescript
import { Toolpack } from 'toolpack-sdk';
import { AnthropicVertexAdapter } from 'toolpack-sdk/providers';

const sdk = await Toolpack.init({
  provider: new AnthropicVertexAdapter({
    projectId: 'my-gcp-project',  // or ANTHROPIC_VERTEX_PROJECT_ID / GOOGLE_CLOUD_PROJECT env var
    region: 'us-east5',           // or ANTHROPIC_VERTEX_REGION env var; defaults to us-east5
  }),
  tools: true,
});
```

**Supported models:**

| Model ID | Description |
|---|---|
| `claude-sonnet-4-5@20250929` | Claude Sonnet 4.5 — 200K context |
| `claude-haiku-4-5@20251001` | Claude Haiku 4.5 — 200K context |
| `claude-3-5-sonnet-v2@20241022` | Claude 3.5 Sonnet v2 — 200K context |
| `claude-3-5-haiku@20241022` | Claude 3.5 Haiku — 200K context |

Full feature parity with the direct Anthropic adapter: streaming, tool calling, vision, and multi-turn conversations.

## Improvements

### VertexAI: new models and thinking budget

Two new Gemini models are available in `VertexAIAdapter`:

| Model ID | Context | Max output |
|---|---|---|
| `gemini-3.5-flash` | 1M tokens | 65,536 tokens |
| `gemini-3.1-pro-preview` | 1M tokens | 65,536 tokens |

**Thinking token budget** — Gemini 2.5+ models support a configurable thinking budget. Set it at construction time:

```typescript
import { VertexAIAdapter } from 'toolpack-sdk/providers';

new VertexAIAdapter({ thinkingBudget: 8192 });   // allocate 8K thinking tokens
new VertexAIAdapter({ thinkingBudget: 0 });       // disable thinking entirely
// omit to use the model's default
```

**`rawContentCache`** — internally, the adapter now caches the raw Vertex AI `Content` object for each tool-call response, keyed by tool call IDs. Gemini thinking models (3.x+) attach a `thought_signature` to function calls that must be replayed in subsequent turns; without it the API rejects the request. The cache is capped at 500 entries (LRU eviction).

### Skills: mode-gated auto-injection

Skill auto-injection via the built-in interceptor is now opt-in per mode. The interceptor checks `mode.skillInterceptor === true` before running BM25 search; modes without this flag are passed through immediately with zero overhead.

```typescript
const researchMode = createMode({
  name: 'research',
  skillInterceptor: true,  // opt in — this mode gets automatic skill injection
});

const chatMode = createMode({
  name: 'chat',
  // no skillInterceptor — BM25 never runs for this mode
});
```

Modes that already set `skillInterceptor: true` are unaffected.
