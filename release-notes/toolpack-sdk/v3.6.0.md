# Toolpack SDK v3.6.0

Date: 2026-11-15

## Highlights

- **`interceptTool` on a request**: one hook that wraps every tool call of that request. It can stop a call, change its result, or just watch it
- **New exported types**: `ToolInterceptor` and `InterceptedToolCall`

---

## New features

### Stop or change a tool call with `interceptTool`

Pass an `interceptTool` function on `generate()` or `stream()`. It is called for every tool call of that request, whatever the tool: request tools, mode tools, registry tools and `tool.search`.

The function gets the call and a `run()` function:

- Call `run()` to run the tool. You can return its result as it is, or change it first
- Return text without calling `run()` to stop the call. The tool does not run, and the model sees your text as the tool's result

```typescript
import type { ToolInterceptor } from 'toolpack-sdk';

const interceptTool: ToolInterceptor = async (call, run) => {
  if (call.toolName === 'fs.delete_file') {
    return 'Deleting files is not allowed in this session.'; // the tool is not run
  }
  const result = await run();
  return result.length > 10_000 ? result.slice(0, 10_000) + '\n[cut]' : result;
};

const response = await toolpack.generate({ model, messages, interceptTool });
```

What the interceptor sees:

| Field | What it is |
|---|---|
| `toolName` | The name of the tool the model called |
| `args` | The arguments the model passed |
| `round` | The tool round of the request (1 for the first). Calls made in parallel in one round share it |

Notes:

- The tool's `tool:started`, `tool:completed` and log events are sent only when `run()` is called. A stopped call sends none
- A stop (`signal`) still wins: once the request is aborted, the interceptor is not asked and no tool is started
- `interceptTool` is only for the SDK. It is never sent to the provider
- Requests without `interceptTool` behave exactly as before

### New exports

| Export | What it is |
|---|---|
| `ToolInterceptor` | `(call: InterceptedToolCall, run: () => Promise<string>) => Promise<string> \| string` |
| `InterceptedToolCall` | `{ toolName, args, round }`, the call as the interceptor sees it |
| `CompletionRequest.interceptTool` | New optional field, `ToolInterceptor` |

---

## Compatibility

- Node.js >= 20
- No new required dependencies
- No breaking changes. Code that does not set `interceptTool` needs no changes

## Install

```bash
npm install toolpack-sdk@3.6.0
npm install @toolpack-sdk/agents@3.6.0
```
